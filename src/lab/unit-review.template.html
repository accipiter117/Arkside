Creator code

Paste an operative or squad export from the Operative Creator to load it (the first operative is shown).

Clothing follows the model’s own shapes, so tank tops, hoodies and jackets all show as the base jacket or hoodie for now (bending cloth would need the Blender step in Phase 2). Gloves recolour the hands. The squad view shows 12 random units at game size, with the frame rate, as a performance check.
